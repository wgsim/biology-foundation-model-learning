## 1. 이 과정의 사용법

### 주간 시간 배분 (주 8~10시간 기준)
| 활동 | 시간 | 내용 |
|---|---|---|
| 읽기 | 3h | 모듈 강의노트 + 필수(★) 논문 1~2편 |
| 실습 | 4h | 노트북 실행 → 코드 수정 → 과제(`exercises.md`) |
| 정리 | 1~2h | 논문 노트·실험 로그 작성, 이해도 점검 문제 풀기 |
| 여유 | 1h | 막힌 곳, 심화(◆/○) 논문 |

### 모듈 완료 기준
- 강의노트의 "이해도 점검" 문제를 답을 보기 전에 풀어 본다.
- 노트북을 **그대로 실행**한 뒤, 과제에서 **한 가지를 바꿔서** 결과가 어떻게 달라지는지 기록한다.
- 모듈마다 산출물 1개: (a) 단순 baseline 재현, (b) split 변경 효과 확인, (c) 동결 표현 vs 미세조정 비교 중 하나.
- 논문 노트 1건 이상 작성 ([paper_note_template.md](paper_note_template.md)).

### 실행 등급
🟢 Mac 로컬(CPU/MPS) · 🟡 Colab GPU · 🔴 기관 클러스터. 환경 설정은 [../SETUP.md](../SETUP.md).

## 3. 생물학 FM 논문을 읽는 법 (3-pass)

**Pass 1 (15분) — 무엇을 주장하는가**
- 제목·초록·그림·결론만 읽는다.
- 한 문장으로 요약: "*[입력]*으로 *[모델]*을 *[목적함수]*로 학습해 *[과제]*에서 *[주장]*."

**Pass 2 (45분) — 주장이 어떤 증거에 기대는가**
- 방법·평가 설계·표/그림을 읽고 아래 체크리스트를 채운다.

**Pass 3 (재현 수준)** — 핵심 수식과 부록을 따라가고, 가능하면 코드를 실행한다.

### 비판적 읽기 체크리스트 (생물학 FM 특화)
1. **입력/토큰**: 무엇이 토큰인가? (단일 잔기, k-mer, BPE, 유전자 등)
2. **목적함수**: MLM / 자기회귀 / 대조학습 / 확산 중 무엇인가?
3. **사전학습 데이터**: 범위, 중복 제거 방식, 수집 시점.
4. **평가 데이터와 사전학습 데이터의 겹침**: 상동성·중복 가능성은?
5. **split 방식**: random인가, 상동성/시간/기관/batch 단위인가?
6. **baseline**: 단순 모델(선형, k-mer, 평균)과 FM 이전 방법(MSA 기반, CNN 등)이 포함되었는가?
7. **평가 설정**: zero-shot / linear probe / fine-tuning 중 무엇인가? 공정하게 비교되었나?
8. **통계**: 반복 실행, 신뢰구간, 효과 크기가 보고되었나?
9. **실험적 검증**: 예측이 wet-lab으로 확인되었는가, 아니면 전부 in silico인가?
10. **접근성**: 코드·가중치·데이터 공개 여부와 라이선스.
11. **한계 서술**: 저자가 스스로 밝힌 한계는 무엇인가?

> 팁: 한 과제에서 FM이 baseline을 못 이긴 결과(예: 단일세포 비판 논문)는 "FM은 쓸모없다"가 아니라 "이 설정에서는 이득이 없었다"로 기록한다.

## 4. 재현 원칙
- **baseline부터**: 모델을 키우기 전에 가장 단순한 방법(빈도, k-mer 로지스틱 회귀)으로 먼저 점수를 낸다.
- **split을 먼저 정하고 기록**: 데이터를 보기 전에 split 규칙을 확정한다.
- **seed·버전 기록**: 난수 시드, 패키지 버전, 체크포인트 ID와 확인 날짜.
- **한 번에 하나만 바꾼다**: 비교 실험에서는 변수 하나만 바꾼다.
- **실패도 기록**: 안 된 실험과 원인 가설을 로그에 남긴다.

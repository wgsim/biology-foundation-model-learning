# 트랙 B·C·D 시험 실행 기록

> **이 기록의 성격**: 트랙 A는 [템플릿 노트북](../../templates/capstone_notebook_template.ipynb)이 직접 실행되지만 B~D는 시작점만 가리키고 있었다. 이 기록은 **과정을 만든 쪽이 각 트랙의 MVP(사전 지정 비교 하나)를 골라 템플릿 구조(사전 등록 → 출처 → 데이터 점검 → 단위·누출 → baseline → 평가 → 대조 → 민감도)로 옮겨 실제로 돌려 본 것**이다.
> - **학습자 파일럿이 아니다.** 학습자가 걸릴 시간이나 막히는 곳은 재지 않았다.
> - **실제 사전 등록이 아니다.** 설계와 결과를 같은 시기에 만들었고 결정 규칙도 결과를 보기 전에 정했다고 증명할 수 없다. 형식을 보여 주려는 [트랙 A 예시](../example_track_A_proposal_and_report.md)와 같은 위치다.
> - 각 비교는 **한 번의 실행**이다. 아래 결과를 "DNA LM / 단일세포 FM / 화학 LM은 …하다"로 일반화하지 말 것.
> - Codex·agy 교차 리뷰를 받지 않았다.

실행 환경: Mac(CPU/MPS), 저장소 `.venv`, 새 다운로드 없음(모듈 03·04·05가 받아 둔 캐시만 사용). 코드는 이 폴더의 스크립트 3개이며 저장소 루트에서 실행한다 (`HF_HOME=$PWD/.cache/hf HF_HUB_OFFLINE=1 .venv/bin/python -I <스크립트>`). 실행 기록(`provenance.json`)은 `.cache/capstone_runs/<RUN_NAME>/`(git 제외)에 쓴다.

## 트랙 B — TraitGym에서 NT LLR vs 보존 점수
- **설정(고정)**: TraitGym `mendelian_traits_matched_9`(변이 3,380, 양성 338, 양성 1개당 매칭된 대조 9개 = `match_group` 338개, 염색체 19개). 지표 AUPRC. 점수의 부호는 데이터를 보기 전에 규정(LLR −, 보존 +). Δ = AUPRC(모델) − AUPRC(baseline). 결정 규칙: 염색체별 Δ(양성 ≥ 5인 14개)의 평균 ≥ 0.02, Δ > 0인 염색체 ≥ 10/14, `match_group` 단위 짝지은 부트스트랩 95% 구간 하한 > 0 → '지지'.
- **데이터 점검(assert)**: 점수 파일과 변이표의 행 수 일치, NaN 없음, 그룹당 양성 정확히 1개, 그룹이 한 염색체 안에 있음, 변이 중복 없음. 모두 통과.
- **AUPRC** (그룹 내 순위 섞기 1,000회의 귀무분포 평균 0.101, 95% 분위수 0.109):

| 점수 | AUPRC | 순열 p |
|---|---|---|
| NT LLR (TraitGym 제공) | 0.103 | 0.338 |
| Evo2-7B LLR | 0.381 | 0.001 |
| phyloP-241m | 0.673 | 0.001 |
| phyloP-100v / phastCons-43p | 0.653 / 0.497 | 0.001 |
| TSS 거리만 (매칭 변수) | 0.115 | 0.006 |

- **주 비교** NT LLR − phyloP-241m: 풀링 Δ −0.571 [−0.618, −0.519], 염색체 평균 Δ −0.561, Δ > 0인 염색체 0/14 → **지지되지 않음**. 보조 비교 Evo2-7B LLR − phyloP-241m: Δ −0.293 [−0.348, −0.231], 1/14 → 지지되지 않음. (두 비교를 모두 사전 지정했고 다중 비교 보정은 하지 않았다.)
- **대조**: 음성 — 모델 점수를 `match_group` 안에서 섞으면 AUPRC 0.096(귀무 평균 0.101). 양성 — Evo2-7B LLR vs TSS 거리만: Δ +0.231, 13/14, 구간 [+0.213, +0.314] → '지지'.
- **민감도(한 번에 하나)**: baseline을 phyloP-100v / phastCons-43p로 바꿔도 모두 지지되지 않음(Δ −0.550 / −0.394). 염색체 기준 양성 수를 3 / 10으로 바꾸면 17개 중 1개 / 10개 중 0개만 Δ > 0.
- 모듈 03 노트북 02의 수치(NT 0.103, Evo2-7B 0.38, phyloP-241m 0.67, TSS 0.115 p = 0.006)와 일치한다.
- **템플릿에서 바꾼 것**: 이 트랙은 *학습이 없다(zero-shot)*. `make_split`·`fit_predict`·`PRED`·Ridge·무작위 초기화 모델이 필요 없고, 시드별 Δ 자리를 **염색체별 Δ**로, `MIN_TEST_GROUPS`를 `MIN_POS_CHROM`과 `match_group` 수로 옮겼다. `decide()`는 그대로 쓸 수 있었다. 음성 대조는 "라벨 섞기"가 아니라 "그룹 내 점수 섞기"다.
- **막힌 곳 / 주의**: ① 질문이 "분할 단위를 바꾸려면 좌표가 있는지 먼저 확인"이라고 했는데, 변이표에 `chrom`·`pos`·`match_group`이 있어 염색체 단위가 가능했다. ② 양성이 2~8개뿐인 염색체의 AUPRC는 매우 흔들린다(그래서 최소 양성 수를 사전 지정했다). ③ 직접 계산한 NT LLR은 chr1 변이 210개(양성 21개)뿐이라 MVP로는 부적합하다 — 제공 점수를 썼다.
- **말할 수 없는 것**: 이 변이 집합·이 지표에서의 비교일 뿐 DNA LM 전체나 다른 질병/복합 형질에는 해당하지 않는다. TraitGym 제공 NT 점수의 모델 변형·창 길이는 확인하지 않았다†.
- **미실시**: 질문의 다른 절반("NT probe의 이득이 층 선택·6-mer baseline 크기에 얼마나 의존하는가")은 NT 임베딩이 캐시에 없어(노트북 03/01은 저장하지 않는다) 실행하지 않았다 — 하려면 03/01을 다시 돌려야 한다(약 8~15분).

## 트랙 C — Geneformer 임베딩 위 지도 head vs PCA head
- **설정(고정)**: Wilk 2020 PBMC 하위표본 10,400세포, 기증자 13명, 기증자 단위 leave-one-donor-out. head = 로지스틱 회귀(C = 1 고정, 중심화·L2 정규화·표준화는 훈련 기증자만으로 적합). 주 비교: V2-104M `<cls>` L-2 vs PCA(HVG, 50), 거친 라벨 13종. 지표: 풀링 macro-F1(기증자 단위 부트스트랩 1,000회) + 기증자별 균형정확도. 결정 규칙: 기증자별 균형정확도 Δ의 평균 ≥ 0.02, Δ > 0인 기증자 ≥ 9/13, macro-F1 Δ 구간 하한 > 0.
- **캐시에서 막힌 곳**: `pbmc_sub.h5ad`에는 세부 라벨(`cell.type.fine`)이 **없고** 세포 이름도 `cell0…`으로 바뀌어 원본과 연결되지 않는다(obs: donor, disease, label, cell_type_cxg, n_counts). 노트북 04/01의 `balanced_subsample`(시드 0, 기증자당 800)이 결정적이라 그것을 `wilk2020_pbmc.h5ad`에 다시 적용했고, 기증자·거친 라벨·cxg 라벨 10,400개가 전부 일치함을 확인한 뒤 세부 라벨 20종을 붙였다 (스크립트가 assert). 새 다운로드는 없다. PCA(HVG)는 캐시에 없어 노트북 04/02와 같은 절차로 만들었다(7초).
- **결과** (거친 13종, 로지스틱 head):

| 표현 | 풀링 macro-F1 | 기증자별 균형정확도 평균 |
|---|---|---|
| PCA(HVG, 50) | 0.856 | 0.841 |
| Geneformer V2 `<cls>` L-2 | 0.838 | 0.806 |
| Geneformer V1 평균 L-2 | 0.724 | 0.691 |
| V1 무작위 초기화 | 0.526 | 0.508 |
| (음성 대조) V2, 훈련 라벨 섞기 | 0.068 | 0.075 (13종 균등 추측 0.077) |

- **주 비교** V2 − PCA: macro-F1 Δ −0.018 [−0.031, −0.009], 기증자별 균형정확도 Δ −0.036, 기증자 3/13 → **지지되지 않음**. 대조 — 사전학습 효과(V1 − V1 무작위 초기화): Δ +0.198 [+0.182, +0.223], 13/13 → '지지'.
- **민감도(한 번에 하나)**: PCA를 held-out 기증자를 빼고 fold마다 적합 → Δ −0.017 [−0.033, −0.003]. head를 kNN(k = 15)으로 → Δ −0.036 [−0.064, −0.018](모듈 04 노트북 02의 zero-shot 수치 PCA 0.847·V2 0.811과 같다). 라벨을 세부 20종으로 → Δ −0.079 [−0.097, −0.062](PCA 0.824, V2 0.744). 모두 지지되지 않음.
- **읽기**: 지도 head는 격차를 줄였지만(kNN −0.036 → 로지스틱 −0.018) PCA 아래에 머물렀고, 라벨이 세분될수록 격차가 커졌다. 한 데이터셋·head 하이퍼파라미터 1개(C = 1)의 결과다.
- **템플릿에서 바꾼 것**: 시드 대신 **기증자**가 단위이고(분할은 결정적), Ridge/Spearman 대신 로지스틱/macro-F1이다. 음성 대조는 "훈련 라벨 섞기", 무작위 초기화 대조는 캐시에 있는 V1 무작위 초기화 임베딩을 썼다.
- **주의**: ① HVG 선택은 모든 세포로 했다(PCA를 fold별로 적합해도 남는 한계). ② 질병 상태가 기증자에 완전히 겹쳐 있다(COVID 7명·정상 6명). ③ `max_iter = 300`에서 로지스틱 수렴 경고가 13번 나왔다. `max_iter`만 3000으로 올린 사본으로 다시 돌리면 경고가 없고 위 수치가 같았다(음성 대조만 0.068 → 0.069).
- **미실시**: 새 데이터셋, 미세조정, scGPT 등 다른 모델.

## 트랙 D — Lipophilicity 군집 분할의 컷오프 스윕 (모듈 05 과제 1)
- **설정(고정)**: Lipophilicity 4,200개(무효 SMILES 0, 중복 0), ECFP4 count(2048) vs ChemBERTa-77M-MLM 평균 풀링 마지막 층(리비전 고정), RidgeCV 선형 head, 5-fold × 5회 반복, 컷오프 {0.3, 0.4, 0.5, 0.6}와 random 분할. 지표 RMSE, Δ = RMSE(ECFP4) − RMSE(MLM)(양수 = MLM이 낫다), Butina 군집 단위 부트스트랩 300회. 결정 규칙: 반복별 Δ 평균 ≥ 0.02, Δ > 0인 반복 ≥ 4/5, 구간 하한 > 0.
- **누출을 숫자로** (첫 반복의 test→train 최근접 Tanimoto):

| 분할 | 군집 수 | 최근접 유사도 중앙값 | p90 | 컷오프 이상 이웃이 train에 남은 test 비율 |
|---|---|---|---|---|
| random | — | 0.697 | 0.865 | — |
| 컷오프 0.3 | 816 | 0.358 | 0.687 | 0.74 |
| 컷오프 0.4 | 1,269 | 0.366 | 0.620 | 0.36 |
| 컷오프 0.5 | 1,652 | 0.420 | 0.653 | 0.25 |
| 컷오프 0.6 | 2,067 | 0.486 | 0.700 | 0.20 |

  컷오프를 높일수록 군집이 잘게 쪼개져 최근접 유사도가 올라간다. 군집이 이행적이지 않아 컷오프 이상의 쌍이 폴드 사이에 남는다(0.3에서 test의 74%).
- **RMSE (5회 반복 평균 ± sd)**:

| 분할 | ECFP4 | ChemBERTa-MLM | MLM 무작위 초기화 | (음성 대조) ECFP4, 라벨 섞기 |
|---|---|---|---|---|
| random | 0.750 ± 0.002 | 0.828 ± 0.002 | 1.033 ± 0.002 | 1.204 |
| 0.3 | 0.906 ± 0.006 | 0.930 ± 0.007 | 1.096 ± 0.005 | 1.204 |
| 0.4 | 0.918 ± 0.008 | 0.917 ± 0.010 | 1.080 ± 0.006 | 1.204 |
| 0.5 | 0.868 ± 0.007 | 0.902 ± 0.004 | 1.082 ± 0.005 | 1.205 |
| 0.6 | 0.827 ± 0.004 | 0.883 ± 0.006 | 1.068 ± 0.005 | 1.204 |

  (y의 표준편차 1.203 — 라벨을 섞으면 이 값으로 수렴해야 하고 그렇게 나왔다.)
- **주 비교** Δ(ECFP4 − MLM) [95% 구간], 반복 Δ > 0: random −0.079 [−0.102, −0.054] 0/5 · 0.3: −0.024 [−0.076, +0.022] 0/5 · 0.4: +0.002 [−0.050, +0.048] 3/5 · 0.5: −0.034 [−0.065, +0.002] 0/5 · 0.6: −0.057 [−0.086, −0.027] 0/5 → **모든 분할에서 지지되지 않음**. 구간이 0을 포함하는 것은 0.3·0.4·0.5이고, 격차는 컷오프에 대해 단조롭지 않다(0.4에서 가장 작고 0.6에서 다시 커진다). 대조 — 사전학습 효과(MLM vs 무작위 초기화): 5개 분할 모두 Δ +0.16 ~ +0.21, 5/5 → '지지'.
- **과제 1의 물음에 대한 관찰**: "컷오프를 올리면 항상 어려워진다"는 가설은 이 설정에서 성립하지 않았다. ECFP4 RMSE는 컷오프 0.3 → 0.6에서 0.906 → 0.827로 대체로 내려갔다(쉬워졌다). 0.3 → 0.4의 오름(0.012)은 반복 sd 0.006~0.008 수준이다. 모듈 05 README의 값(random 0.750, 군집 0.4 근처 0.923; 반복 3회)과 같은 범위다.
- **템플릿에서 바꾼 것**: Ridge·Spearman을 RidgeCV·RMSE로, 위치 블록을 Butina 군집으로 바꿨다. random 분할에는 군집 단위가 없어 부트스트랩 단위를 컷오프 0.4 군집으로 임의로 두었다(구간의 의미가 다른 칸과 완전히 같지는 않다). 노트북 05/01의 함수는 셀 안에 있어 import할 수 없어 `balanced_group_folds`·Butina·ChemBERTa 풀링 코드를 스크립트로 복사했다.
- **말할 수 없는 것**: Lipophilicity 하나, 동결 임베딩 + 선형 head, 레이어·풀링 고정(마지막 층 평균). 다른 과제·미세조정·MTR 변형은 다루지 않았다.
- **미실시**: 과제 2(표기 증강 vs 정규화), 과제 5(거짓 음성 마스킹).
- **비용 주의**: README는 트랙 D의 비용을 🟢로 적었는데, 이 MVP 하나가 약 14분이었다(대부분 ECFP4 2048차원 RidgeCV).

## 공통으로 확인한 것
1. **세 트랙 모두 새 다운로드 없이 캐시만으로 MVP를 끝까지 돌릴 수 있었다.** 막힌 곳은 하나(트랙 C의 세부 라벨)였고 결정적 재현으로 풀렸다.
2. **템플릿 노트북 그대로는 안 되고, 구조는 옮겨 쓸 수 있었다.** 바꾼 것은 데이터 로딩, 특징, 분할/단위(시드 → 염색체·기증자·반복), 지표뿐이었다. `decide()`와 "사전 등록 → 출처 → 점검 → 대조 → 민감도" 순서는 그대로 썼다. 트랙 B처럼 학습이 없는 비교에는 `make_split`/`fit_predict` 인터페이스가 맞지 않는다.
3. **대조는 트랙마다 다시 정의해야 했다.** 음성 대조는 B "그룹 내 점수 섞기", C "훈련 라벨 섞기", D "라벨 섞기"였고, 결정 규칙이 '지지'를 낼 수 있음을 보이는 양성 대조는 B "Evo2-7B vs TSS 거리만", C·D "사전학습 vs 무작위 초기화"였다. 이 양성 대조를 넣지 않았다면 세 트랙의 "지지되지 않음"이 규칙의 편향인지 구분하지 못했을 것이다.
4. 세 주 비교가 모두 "지지되지 않음"으로 나온 것은 질문의 *선택* 때문이기도 하다(FM이 강한 baseline을 이길지 묻는 질문). 새로운 결론이 아니라 모듈 03·04·05의 방향과 같다.

## 이 기록에서 하지 않은 것
- 학습자 파일럿(소요 시간·막힘 측정), 트랙 E 후보 논문 선정, 질문의 나머지 절반들(위 각 트랙의 "미실시").
- 이 기록과 스크립트는 교차 리뷰를 받지 않았다.

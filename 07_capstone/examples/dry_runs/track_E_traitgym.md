# 트랙 E 시험 실행: TraitGym 논문 재현 (L1 + L3) — 2026-11-09

[후보 조사](../track_E_candidates.md)에서 1순위로 고른 TraitGym(Benegas, Eraslan, Song 2025, bioRxiv 10.1101/2025.02.11.637758)을 [캡스톤 §3 프로토콜](../../README.md#3-트랙-e-논문-재현-프로토콜)에 따라 한 번 돌려 본 기록이다. 스크립트: [track_E_traitgym_reproduction.py](track_E_traitgym_reproduction.py)(140초, Mac, 점수는 캐시·공개 지표 CSV는 새로 내려받음).

> **이 기록의 성격**
> - **학습자 파일럿이 아니다.** 과정을 만든 쪽이 한 번 돌렸다.
> - **논문 본문을 읽지 않았다.** 핵심 주장 문장(프로토콜 1단계 ①)은 정하지 못했다. 여기서 말하는 "주장 단위"는 *공개 지표 CSV의 숫자 한 칸*이다.
> - **재현 수준은 L1의 "점수 → 지표 계산"까지**이다. 프로토콜의 L1은 공개 코드·가중치로 수치를 얻는 것인데, 여기서는 **공개 점수 파일(캐시)** 에서 출발해 **지표 계산**을 재현했다. 모델을 돌려 점수를 만드는 단계는 하지 않았다(모듈 03에서 NT LLR을 chr1 변이 210개에서 직접 계산했을 때 공개 점수와 Spearman 0.87이었다 — 그 단계의 재현은 정확하지 않았다).
> - 허용 오차와 판정 규칙은 공개 workflow 코드를 읽은 **뒤**, 결과를 보기 **전에** 스크립트에 적었다. 실제 사전 등록이 아니다.
> - Codex·agy 교차 리뷰를 받았다(맨 아래 "교차 리뷰" 절).

## 사전 지정한 것 (스크립트 머리)
- **L1**: 공개 `score`와 재계산 값의 |차이| ≤ **0.001**(22개 값 모두). 계산이 결정적이라 시드 변동이 없으므로(프로토콜 3의 "시드로 변동을 잰다"는 해당 없음) 공개 se(0.005~0.10; 가장 작은 se도 허용 오차의 5배 이상)보다 작은 값으로 정했다. `se`는 공개 코드가 polars 난수열을 쓰는데 이 환경에 polars가 없어 numpy로 재구현했으므로 **판정에 쓰지 않고** ±15%(1,000회 부트스트랩의 표준오차 약 2%의 7배)를 참고 기준으로만 봤다.
- **L3**: 공개 `all` 순위와 변형 순위의 Kendall τ ≥ **0.80**이면 "순위 유지". 양성이 **30개 미만**인 부분집합은 순위가 잡음이라 판정하지 않는다.
- 공개 코드의 지표 정의(옮김): 염색체마다 `average_precision_score`를 계산하고 **염색체의 변이 수로 가중 평균**한다. `se` = 염색체 표의 행을 복원추출한 1,000회 부트스트랩의 표준편차. 점수의 부호는 파일 이름의 `plus`/`minus`.

## 실패 검출 대조 (검사가 실제로 실패할 수 있는가)
이 트랙의 결정 규칙은 "22개 값이 허용 오차 안"이라, 다른 트랙에서 쓰는 '양성·음성 대조'(규칙이 '지지'를 낼 수 있는가 / 섞은 라벨이 우연 수준인가) 대신 **일부러 틀린 입력·정의에서 검사가 실패하는가**를 본다. 통과할 수 있다는 쪽의 확인은 L1 자체다.
- **① 부호 뒤집기**: 점수의 부호를 뒤집으면 17개 **모두** 허용 오차를 벗어난다(최소 |Δ| 0.003). 허용 오차(0.001)가 정의의 차이를 잡을 만큼 좁다 — 다만 최소 |Δ|가 허용 오차의 3배라 여유가 크지는 않다.
- **② 점수 섞기**: `match_group` 안에서 점수를 섞으면 가중 AUPRC 평균이 0.124(양성 비율 0.100)이고 17개 모두 공개 값과 다르다. 0.100이 아니라 0.124인 것은 염색체별 AP가 작은 표본에서 우연 기대값보다 높게 나오기 때문으로 보인다(이 실행에서 확인하지 않았다†).
- **③ 정의가 다르면 어긋난다**: 풀링 AUPRC는 최대 |Δ| 0.049, 염색체 동일 가중 평균은 최대 0.077로 17개 모두 공개 값과 다르다. 일치가 우연이 아니라 *변이 수 가중 염색체 평균* 정의에서 나온 것임을 보인다.

† 교차 리뷰의 지적 뒤에 추가한 행이다. 사전 지정한 부분집합 행은 **풀링 AUPRC**였고 기준 순위(`all`)는 **가중 평균**이라 부분집합과 지표가 함께 바뀌었다 — 그래서 같은 지표(가중 평균)로 부분집합만 바꾼 행을 더했다. 판정 규칙(τ ≥ 0.80, 양성 ≥ 30)은 두 지표에 같게 적용했다.

- **읽기**: 지표 정의를 바꿔도(풀링, 동일 가중) 순위는 유지된다(τ ≥ 0.94, 내부 안정성 수준). 부분집합 5개 중 3'UTR은 양성이 29개라 판정하지 않았고, 판정한 4개 중 2개(non-coding transcript exon, nonexonic proximal)는 두 지표 모두에서 유지, 2개(5'UTR, nonexonic distal)는 두 지표 모두에서 유지되지 않는다(distal의 가중 평균 τ는 0.794로 임계값 근처). distal·풀링에서는 1위가 GPN-MSA LLR로, 5'UTR·가중 평균에서는 evo2_7b LLR로 바뀐다.
- **무엇을 말할 수 없는가**: τ(0.69~0.79)가 내부 안정성 τ(0.87~0.90)보다 낮지만, 이것은 부분집합의 실제 순위 차이를 보여 주는 검정이 아니다. 공개 순위 자체에도 표본 변동이 있고 `τ(공개, 부분집합)`의 귀무분포(전체에서 같은 크기의 부분집합을 뽑았을 때)를 만들지 않았다. 하위권 모델들의 점수가 가까워(0.098~0.120) 몇 쌍의 뒤바뀜만으로 τ가 내려가는 영향도 확인하지 않았다.
- **부분집합의 `match_group` 온전성**: `nonexonic_AND_*`는 교집합 뒤 그룹 완결성을 다시 맞추지 않지만(공개 코드와 같음), 이 데이터에서는 5개 부분집합 모두 `match_group` 전부가 크기 10·양성 1개로 온전했고 양성이 없는 그룹은 0개였다(29/114/71/34/90개). 그룹 부트스트랩이 조각난 그룹을 뽑는 문제는 없었다.
- **사전 지정한 변형만 봤다.** 부분집합 5개는 공개 CSV가 있는 것이라 골랐고, 다른 부분집합·다른 지표(AUROC)·다른 데이터셋(`complex_traits_matched_9`)에서의 순위는 보지 않았다.

## 말할 수 없는 것
- **논문의 주장.** 논문 본문·그림·표를 읽지 않았다. 공개 CSV가 프리프린트의 표와 같은 숫자인지도 확인하지 않았다(저장소에 `mendelian_traits_v21_`·`v22_matched_9` 폴더가 따로 있다).
- **모델 수준 재현.** 공개 점수 파일에서 지표를 다시 계산해 공개 지표와 맞는다는 것만 보였다(점수 자체가 맞다는 뜻이 아니다). 점수가 모델에서 나온 방식은 재현하지 않았다.
- **다른 모델·데이터셋.** `all`의 나머지 64개 모델(점수 파일이 캐시에 없음), `complex_traits_*`(약 4.2 GB), `no_cadd_overlap`(CADD 학습 겹침 파일이 필요)은 다루지 않았다.

## 템플릿에서 바꾼 것 (트랙 E에 필요한 조정)
- `make_split`·`fit_predict`·시드·`PRED`가 필요 없다: 학습이 없고 계산이 결정적이다. 단위는 시드 대신 **모델(17개)·염색체**이다.
- `decide()`(효과 크기·승수·구간) 대신 **허용 오차 규칙**(|Δ| ≤ ε, 22개 모두)과 **Kendall τ 규칙**이 결정 규칙이다. 프로토콜 3단계의 "원 코드를 시드만 바꿔 돌려 변동을 잰다"는 결정적 계산에는 적용되지 않아, 허용 오차를 공개 se와 반올림 수준에서 정했다.
- **대조의 뜻이 바뀐다**: "검사가 실패할 수 있는가"(부호 뒤집기, 점수 섞기, 다른 정의)를 보는 *실패 검출 대조*가 양성·음성 대조를 대신한다.
- **편차 기록**과 **재현 수준 표기**(여기서는 "L1: 점수 → 지표")를 보고서 §1·§5에 넣어야 한다.

## 하지 않은 것
- 논문 본문 읽기와 주장 문장 확정, 점수 생성 단계(모델 실행)의 재현, 부분집합 순위 차이의 귀무분포, `complex_traits`·AUROC 변형.
- 학습자 파일럿.

## 교차 리뷰 (2026-11-09)
스크립트·이 문서·README 수정·실행 로그·공개 workflow 코드 발췌를 Codex(gpt-6.1-terra)와 agy(gemini-4-argon-low)에 읽기 전용으로 보여 주고 검토받았다(Codex 7건, agy 6건). 표의 수치는 두 리뷰어 모두 로그와 일치한다고 확인했다.

**반영한 것**
- **proximal/distal 설명이 뒤집혀 있었다 (Codex·agy)**: 공개 코드의 식은 음성을 모두 두고 *양성*만 `tss_dist`로 거른다. 구현은 맞았고 설명(코드 주석·문서)만 반대였다 → 수정.
- **L3 부분집합의 지표가 기준과 달랐다 (Codex·agy)**: 위 †행 추가(같은 지표로 부분집합만 바꾼 비교). 결론(어느 부분집합이 유지·비유지인지)은 두 지표에서 같았다.
- **"순위 잡음 τ" 해석 (Codex·agy)**: 스크립트 출력의 "표본 변동만으로 설명된다"가 과했다 → 변형 내부 안정성이며 귀무분포가 아니라고 고쳤다(출력·문서).
- **표현 (Codex)**: CSV의 리비전은 스크립트가 assert하지 않는다(캐시 스냅샷 이름만), se는 "통계적으로 같다"가 아니라 참고 기준 안, "공개 점수가 맞다"는 점수 자체가 맞다는 뜻이 아니다 → 수정. 허용 오차 근거의 se 범위(스크립트 주석 0.04~0.07 → 0.005~0.10)와 노트북의 NaN 처리 차이 추가.
- **대조 이름 (agy)**: '양성·음성 대조'가 다른 트랙의 뜻과 달라 혼란스러워 "실패 검출 대조 ①②③"으로 바꾸고 이유를 적었다. `load_score`의 `split(tag, 1)`(agy)도 반영.

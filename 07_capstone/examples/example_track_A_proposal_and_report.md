# 예시 — 트랙 A: 동결 ESM-2 8M probe는 *새 위치*에서 위치 baseline을 이기는가? (DN7A)

> **이 예시의 성격**: 형식을 보여 주려고 [템플릿 노트북](../templates/capstone_notebook_template.ipynb)의 실제 실행 결과(약 20초, 시드 5개)로 채웠다. **실제 사전 등록이 아니다** — 설계와 결과를 같은 시기에 만들었다. 학습자의 프로젝트는 제안서를 결과 전에 확정해야 한다. 결론을 다른 단백질·모델로 일반화하지 말 것. 마지막의 루브릭 자기 평가는 *이 예시가 아직 완성된 캡스톤이 아님*을 보여 준다.

# Part 1. 제안서 (요약형)
- **트랙/등급**: A · 🟢 Mac (약 20초) · 다운로드·설치 없음(모듈 02·06 캐시)

## 질문과 주장 범위
- 질문: "DN7A 안정성 assay의 단일 치환에서, 동결 ESM-2 8M의 변이 위치 임베딩 + Ridge probe는 **train에 없던 위치 블록**을 예측할 때 위치 원-핫을 쓰는 baseline(B2)보다 Spearman이 높은가?"
- 주장할 수 있는 최대 범위: 이 assay 하나, ESM-2 8M 하나, Ridge probe, 시드 5개.
- **말할 수 없는 것**: 다른 assay·모델 크기, 파인튜닝, 층 선택, 사전학습 코퍼스와의 겹침 영향.

## 데이터·출처
| 항목 | 내용 |
|---|---|
| 데이터 | ProteinGym v1.3 치환 DMS, `DN7A_SACS2_Tsuboyama_2023_1JIC` (길이 55, 단일 치환 1,008개, 위치 55개) |
| 해시 | zip `3a83766254ac9ac9…`, 참조 CSV `a8f498011532a74a…` (provenance.json) |
| 모델 | `facebook/esm2_t6_8M_UR50D` @ `c731040fcd8d73dceaa04b0a8e6329b345b0f5df`, 로컬 스냅샷 경로에서 로드 |
| 라이선스 | ESM-2 가중치 MIT(HF 메타데이터), ProteinGym 저장소 코드 MIT(GitHub API), **개별 DMS 데이터는 미확인** |
| 중복 | `mutant` 고유성을 assert로 확인(단일 치환이라 서열 중복 없음) |

## 분할·비교·지표
- 막으려는 누출 경로: **같은 위치의 다른 치환이 train에 있는 것**. 규칙: random(20% test) vs position-block(연속 10개 위치 블록 단위 20% test). 분할 후 측정: test 위치가 train에 있는 비율, 같은 wt→mt 쌍이 train에 있는 비율, train까지 위치 거리.
- 비교: **B1**(wt·mutant 원-핫 + BLOSUM62), **B2**(B1 + 위치 원-핫), **probe**(동결 8M, 변이 위치 마지막 층), **probe-randinit**(무작위 초기화, 시드 0), 음성 대조 **probe-shuffled**. 모두 같은 Ridge 파이프라인(표준화 → Ridge, α는 학습 안 그룹 3-fold CV).
- 주 지표 Spearman. **주 비교**: position-block에서 probe − B2. 시드 5개(분할·초기화 모두 변경), 구간 = 각 시드 test의 위치 블록 재표본(B=500)을 시드에 걸쳐 평균(조건부 구간).
- **결정 규칙**: Δ의 95% 구간이 0을 포함하지 않고 양수이면 '지지', 아니면 '지지되지 않음'.
- 설정은 **사전 고정**(블록 10, Ridge, 마지막 층). 민감도: 블록 크기 {3, 5, 10}(보고용).
- 책임성: 단백질 안정성 예측으로 이중 용도 위험은 낮다고 판단하나 †, 소속 기관 정책 확인은 해당 없음으로 가정. DMS 데이터 라이선스는 공개 전 확인 필요.

# Part 2. 보고서 (요약형)
## 요약
DN7A의 새 위치 블록을 예측할 때 동결 ESM-2 8M probe는 위치 baseline B2보다 **낮았다**(Δ = −0.065 [−0.086, +0.034], 이긴 시드 0/5) → 사전 지정한 규칙에서 **'지지되지 않음'**. random 분할에서는 probe와 B2가 구분되지 않았다(+0.010). 이 결과는 한 assay · 8M · Ridge · 시드 5개에 한정된다.

## 분할과 누출 측정 (시드 평균)
| 분할 | test 위치가 train에 있음 | 같은 wt→mt 쌍이 train에 있음 | train까지 위치 거리 중앙값 |
|---|---|---|---|
| random | 1.00 | 0.88 | 0 |
| position-block | 0.00 | 0.77 | 4.6 |

position-block은 위치 공유 경로를 막지만(0.00), 인접 위치(거리 4.6)와 치환 유형(0.77)은 여전히 train에 있다.

## 결과 (test Spearman, 시드 평균)
| 방법 | random | position-block |
|---|---|---|
| B1 | 0.69 | 0.59 |
| B2 | 0.80 | 0.57 |
| probe | 0.81 | 0.50 |
| probe-randinit | 0.64 | 0.44 |
| probe-shuffled (음성 대조) | −0.02 (SD 0.09) | −0.08 (SD 0.19, \|ρ\| 최대 0.29) |

| 짝지은 Δ [구간] (이긴 시드) | random | position-block |
|---|---|---|
| probe − B2 | +0.010 [−0.012, +0.026] (4/5) | **−0.065 [−0.086, +0.034] (0/5)** |
| probe − B1 | +0.112 [+0.075, +0.154] (5/5) | −0.083 [−0.107, +0.004] (0/5) |
| probe − probe-randinit | +0.167 [+0.129, +0.204] (5/5) | +0.063 [+0.011, +0.135] (4/5) |

민감도(블록 크기 3 / 5 / 10): Δ(probe − B2) 시드 평균 −0.064 / −0.013 / −0.065, 이긴 시드 2/5 · 2/5 · 0/5.

## 해석
- **직접 지지**: 새 위치에서 probe(0.50)는 B1(0.59)·B2(0.57)보다 낮았고 사전 지정 판정은 '지지되지 않음'이다. random 분할의 probe(0.81)는 B2(0.80)와 같다. 사전학습의 기여(probe − 무작위 초기화)는 양수이지만 position-block에서 작고 구간이 넓다(+0.063).
- **가설 수준**: random 분할의 높은 점수는 위치 효과(test 위치가 train에 100%)로 설명된다는 해석은 위 누출 표와 일치하지만, 요인을 분리하는 실험은 하지 않았다. probe가 B1보다 낮은 이유(학습 변이 약 800개 대 320차원 선형 head의 한계, 8M 표현의 한계 등)는 확인하지 못했다.
- **말할 수 없음**: 다른 assay·모델 크기·파인튜닝·층 선택. 블록 크기 5에서는 차이가 거의 0이어서 결론은 분할 설정에 일부 의존한다.

## 한계와 하지 않은 것
한 assay · 8M · Ridge만 · 마지막 층만 · 시드 5개, 구간은 고정된 예측에 대한 조건부 구간(분할·재학습 변동 미포함), 학습 없는 baseline(예: 가장 가까운 train 위치의 평균)을 넣지 않음, DMS 데이터 라이선스 미확인, 이중 용도 검토는 서술 수준, 독립 검토는 받지 않음.

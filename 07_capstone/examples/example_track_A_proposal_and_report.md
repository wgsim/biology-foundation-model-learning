# 예시 — 트랙 A: 동결 ESM-2 8M probe는 *새 위치*에서 위치 baseline을 이기는가? (DN7A)

> **이 예시의 성격**: 형식을 보여 주려고 [템플릿 노트북](../templates/capstone_notebook_template.ipynb)의 실제 실행 결과(약 20초, 시드 5개)로 채웠다. **실제 사전 등록이 아니다.** 설계와 결과를 같은 시기에 만들었고 규칙도 결과를 본 뒤 한 번 고쳤다(변경 기록 참고). 그래서 아래의 "설정/규칙"은 모두 **시연용으로 정한 것**이다. 학습자의 프로젝트는 제안서를 결과 전에 확정(커밋)해야 한다. 결론을 다른 단백질·모델로 일반화해서는 안 된다. 마지막의 루브릭 자기 평가는 *이 예시가 아직 완성된 캡스톤이 아님*을 보여 준다.

# Part 1. 제안서 (요약형)
- **트랙/등급**: A · 🟢 Mac (약 20초) · 다운로드·설치 없음(모듈 02·06 캐시)

## 질문과 주장 범위
- 질문: "DN7A 안정성 assay의 단일 치환에서, 동결 ESM-2 8M의 변이 위치 임베딩 + Ridge probe는 **train에 없던 위치 블록**을 예측할 때 위치 원-핫을 쓰는 baseline(B2)보다 Spearman이 높은가?"
- 주장할 수 있는 최대 범위: 이 assay 하나, ESM-2 8M 하나, Ridge probe, 시드 5개.
- **말할 수 없는 것**: 다른 assay·모델 크기, 파인튜닝, 층 선택, 사전학습 코퍼스와의 겹침 영향.

## 데이터·출처
| 항목 | 내용 |
|---|---|
| 데이터 | ProteinGym v1.3 치환 DMS, `DN7A_SACS2_Tsuboyama_2023_1JIC` (길이 55, 단일 치환 1,008개, 위치 55개) |

| 라이선스 | ESM-2 가중치 MIT(HF 메타데이터), ProteinGym 저장소 코드 MIT(GitHub API), **개별 DMS 데이터는 미확인** |
| 중복 | `mutant` 고유성을 assert로 확인(단일 치환이라 서열 중복 없음) |

## 분할·비교·지표
- 막으려는 누출 경로는 **같은 위치의 다른 치환이 train에 있는 것**이다. 분할 규칙은 random(20% test)과 position-block(연속 10개 위치 블록 단위 20% test)을 비교한다. 분할 후에는 test 비율, test 위치가 train에 있는 비율, 같은 wt→mt 쌍이 train에 있는 비율, train까지 위치 거리, **test 군집(블록) 수**를 측정한다.
- 비교: **B0**(가장 가까운 train 위치의 평균이며, 파라미터를 학습하지 않고 train 라벨만 쓴다), **B1**(wt·mutant 원-핫 + BLOSUM62), **B2**(B1 + 위치 원-핫), **probe**(동결 8M, 변이 위치 마지막 층), **probe-randinit**(시드마다 새로 만든 무작위 초기화), 음성 진단 **probe-shuffled**. B1·B2·probe·randinit는 같은 Ridge 파이프라인(표준화 뒤 Ridge, α는 학습 안 그룹 3-fold CV)을 쓴다.
- 주 지표는 Spearman이다. **주 비교**는 position-block에서 probe − B2이며, 시드 5개를 쓴다. 분할과 무작위 초기화는 시드마다 바뀌고, 시드 반복의 test 집합은 서로 겹친다.
- **시연용으로 정한 결정 규칙**은 코드의 `decide()` 한 곳에 정의한다. Δ 시드 평균 ≥ 0.02, Δ > 0인 시드 ≥ 4/5, 그리고 구간을 계산할 수 있을 때(모든 시드의 test 군집 ≥ 8) 95% 구간 하한 > 0이면 '지지'다. 그 밖에는 '지지되지 않음'이다. 구간은 위치 블록 단위 그룹 부트스트랩이며 조건부이고, 시드 간 중첩은 반영하지 못한다.
- 시연용으로 정한 설정은 블록 10, Ridge, 마지막 층이다. 민감도는 블록 크기 {3, 5, 10}에서 보며 보고용이다.
- 책임성: 단백질 안정성 예측이라 이중 용도 위험은 낮다고 판단한다 †. 소속 기관 정책 확인은 해당 없음으로 가정한다. DMS 데이터 라이선스는 공개 전에 확인해야 한다.

# Part 2. 보고서 (요약형)
## 요약
DN7A의 새 위치 블록을 예측할 때 동결 ESM-2 8M probe는 위치 baseline B2보다 낮았다(Δ 시드 평균 −0.065, 0/5 시드). 시연용 결정 규칙에서 판정은 **'지지되지 않음'**이다(test 군집이 2개뿐이라 구간은 계산하지 않았다). random 분할에서는 probe와 B2의 차이가 작고 부호가 시드마다 바뀌었다(+0.010, 4/5). 한 assay · 8M · Ridge만 · 시드 5개에 한정된다.

## 분할과 누출 측정 (시드 평균)
| 분할 | test 비율 | test 위치가 train에 있음 | 같은 wt→mt 쌍이 train에 있음 | train까지 위치 거리 중앙값 | test 군집 수 |
|---|---|---|---|---|---|
| random | 0.20 | 1.00 | 0.88 | 0 | 6 |
| position-block | 0.31 | 0.00 | 0.77 | 4.6 | 2 |

position-block은 위치 공유 경로를 막지만(0.00), 인접 위치(거리 4.6)와 치환 유형(0.77)은 여전히 train에 있다. 블록 크기가 균일하지 않아(마지막 블록은 5개 위치) test 비율이 20%가 아니라 31%이고 train이 더 작다. test 군집이 2개뿐이므로 **그룹 부트스트랩 구간을 계산하지 않았다**.

## 결과 (test Spearman, 시드 평균)
| 방법 | random | position-block |
|---|---|---|
| B0 (가장 가까운 train 위치 평균) | 0.69 | −0.04 (NaN 1개 제외) |
| B1 | 0.69 | 0.59 |
| B2 | 0.80 | 0.57 |
| probe | 0.81 | 0.50 |
| probe-randinit | 0.64 | 0.49 |
| probe-shuffled (음성 진단) | −0.02 (SD 0.09) | −0.08 (SD 0.19, \|ρ\| 최대 0.29) |

| 짝지은 Δ (시드별, 이긴 시드) | random | position-block |
|---|---|---|
| probe − B2 | +0.010 (+0.02, +0.01, +0.02, +0.01, −0.02; 4/5) | **−0.065 (−0.00, −0.01, −0.06, −0.19, −0.06; 0/5)** |
| probe − B1 | +0.112 (5/5) | −0.083 (0/5) |
| probe − probe-randinit | +0.167 (5/5) | +0.012 (+0.08, +0.05, +0.12, −0.12, −0.07; 3/5) |

민감도는 블록 크기 3 / 5 / 10에서 test 군집이 최소 4 / 3 / 2개였고, Δ(probe − B2) 시드 평균은 −0.064 / −0.013 / −0.065, 이긴 시드는 2/5 · 2/5 · 0/5였다.

## 해석
- **직접 지지**: 새 위치에서 probe(0.50)는 B1(0.59)·B2(0.57)보다 낮았고 시연용 규칙에 따른 판정은 '지지되지 않음'이다. random 분할의 probe와 B2의 차이는 작고 시드마다 부호가 바뀌어 **방향을 확정하지 못했다**.
- 사전학습의 기여(probe − 무작위 초기화, 시드마다 새 초기화)는 random 분할에서 뚜렷하지만(+0.167), position-block에서는 **방향을 확정하지 못했다**(+0.012, 3/5). 무작위 초기화 하나(시드 0)로만 비교했다면 +0.06처럼 보였을 것이다. 대조군이 하나뿐이면 그 초기화의 운이 결론이 된다.
- **가설 수준**: random 분할의 높은 점수는 위치 효과(test 위치가 train에 100%)로 설명된다는 해석은 위 누출 표와 일치하지만 요인을 분리하는 실험은 하지 않았다. probe가 B1보다 낮은 이유(학습 변이 약 700개 대 320차원 선형 head의 한계, 8M 표현의 한계 등)는 확인하지 못했다.
- **말할 수 없음**: 다른 assay·모델 크기·파인튜닝·층 선택. 블록 크기 5에서는 차이가 거의 0이어서 결론은 분할 설정에 일부 의존한다.

## 한계와 하지 않은 것
한 assay와 8M만 다뤘고 Ridge와 마지막 층만 썼다. 시드는 5개이며, test 집합이 겹치는 분할 반복이라 독립 반복이 아니다. **test 군집이 2~6개뿐이라 구간을 계산하지 않았다.** 무작위 초기화 대조군은 5개이고 사전학습 모델은 하나다. 학습 변이 수가 분할마다 다르다(random ≈ 806, position-block ≈ 700). DMS 데이터 라이선스는 미확인이다. 이중 용도 검토는 서술 수준이다. 독립 검토는 받지 않았다. 노트북 실행 시 `repo_dirty=True`였다(정식 제출은 커밋 후 실행한다).

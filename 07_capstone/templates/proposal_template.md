# 캡스톤 제안서 (사전 등록) 템플릿

**결과를 만들기 전에** 작성하고 *커밋*한 뒤(또는 타임스탬프가 남는 곳에 보관한 뒤) 작성 날짜와 그 커밋 해시를 적는다. 날짜를 적은 문서만으로는 사후 작성이 아님을 보일 수 없다. 이후 바꾼 것은 모두 맨 아래 "변경 기록"에 날짜·이유와 함께 남긴다. 변경 자체는 괜찮고, 숨기는 것이 문제다.

```markdown
# [프로젝트 제목]
- 작성일 / 커밋:
- 트랙: A 단백질 · B DNA/게놈 · C 단일세포 · D 분자/멀티모달 · E 논문 재현
- 컴퓨팅 등급: 🟢 Mac / 🟡 Colab / 🔴 클러스터 (예상 소요 시간·비용)

## 1. 질문과 주장 (한 문장씩)
- 질문: "[설정]에서 [방법 A]가 [방법 B]보다 [지표]에서 나은가?"
- 주장할 수 있는 최대 범위(일반화 한계): 한 데이터셋 / 한 모델 크기 / 시드 N개 …
- 이 프로젝트의 결과로 **말할 수 없는 것**:

## 2. 데이터와 출처
| 항목 | 내용 |
|---|---|
| 데이터 이름 / 버전 / 파일 해시 | |
| 내려받기가 필요한가 (파일·출처·크기; 사용자 승인) | |
| 라이선스 (확인한 근거: 파일/페이지/API 필드) | 확인 못 하면 "미확인" |
| 라벨의 출처와 불확실성 (실험 / 주석 / 서열 유사성에서 옮겨 붙은 것) | |
| 중복 처리 규칙 (서열 / 분자 / 텍스트 / 세포) | |
| 사전학습 데이터와 겹칠 가능성 | 확인했나, 못 했나 |

## 3. 분할 (데이터를 보기 전에)
- 막으려는 누출 경로:
- 분할 규칙 (단위: 변이 / 위치 블록 / 가족 / 기증자 / scaffold / 기관):
- 분할 후 **누출을 숫자로 재는 방법** (예: test→train 최근접 유사도, 위치·가족 공유 비율):
- 반복/시드: (분할과 초기화가 함께 바뀌는가. 같은 데이터를 다시 분할한 시드 반복은 test가 겹치므로 독립 반복이 아니다)
- test의 위치·그룹 수 하한 (이보다 적으면 그룹 부트스트랩을 쓰지 않고 시드별 값으로 판단한다):

## 4. 비교 대상
| 이름 | 학습 필요? | 이 비교가 보여 주는 것 |
|---|---|---|
| 파라미터를 학습하지 않는 baseline (최근접 전이 / 가장 가까운 train 위치의 평균 …; train 라벨은 쓰되 train에서만 추정) | 아니오 | |
| 단순 특징 baseline (원-핫 / 조성 / 지문 / 기술자 …) | 예 | |
| 무작위 초기화 대조군 (**시드마다 새로** 생성) | | 사전학습의 기여 |
| 모델 (체크포인트 ID + **리비전**) | | |
- 모든 방법은 **같은 절차·같은 분할**로 평가한다 (head, 표준화, 규제 선택).

## 5. 지표와 결정 규칙
- 주 지표 (하나):  보조 지표:
- **주 비교** (하나): [방법] − [baseline], 짝지은 차이
- 불확실성: 시드 N개를 쓰고, test 군집이 충분할 때(최소 군집 수: )만 **상관 단위의 그룹 부트스트랩**을 쓴다. 이때 조건부 구간임을 명시한다. 부족하면 구간을 계산하지 않고 시드별 값과 효과 크기 규칙으로 판단한다.
- 결정 규칙 ("지지"/"지지되지 않음"을 무엇으로 정하는가. 효과 크기 하한 · 이긴 시드 수 · 구간 조건을 **코드의 함수 하나**로 정의한다):
- 설정 선택: **사전 고정** / 검증 분할로 선택 (test로 고르지 않는다). 민감도는 보고용.

## 6. 민감도와 음성 대조
- 한 번에 한 요인만 바꾸는 민감도 (무엇을, 어느 범위로):
- 음성 진단 (라벨 섞기 / 입력 섞기 / 무작위 초기화)의 기대 결과 (평균이 0 근처이고, 벗어나면 누출·버그를 조사한다. 진단이지 증명이 아니다):

## 7. 책임성
- 라이선스 제약 (재배포·상업 이용·접근 승인):
- 이중 용도 검토 (결과/모델이 오용될 수 있는 기능이 있는가, 공개 범위):
- 소속 기관 정책·심사가 필요한 항목:

## 8. 위험과 미리 적는 한계
- 실패할 수 있는 지점 3개:
- 결과가 음성(효과 없음)이어도 보고할 것인가: 예

## 9. 일정 (2주, 16~20시간)
| 마일스톤 | 산출물 | 예상 시간 |
|---|---|---|
| M1 제안서·승인 | 이 문서 | |
| M2 데이터·분할·baseline | 누출 측정 표, baseline 결과 | |
| M3 주 실험 | 짝지은 비교 + 구간 | |
| M4 민감도·대조 | 표 | |
| M5 보고서 | report_template | |
| M6 독립 검토 | 검토 지적 처리 기록 | |

## 변경 기록
| 날짜 | 바꾼 것 | 이유 | 오류를 관찰한 시점 / 주 비교 결과를 보았는가 |
|---|---|---|---|
```

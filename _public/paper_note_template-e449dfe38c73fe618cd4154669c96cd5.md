# 논문 노트 템플릿

복사해서 논문마다 1건 작성한다.

```markdown
# [논문 제목] (저자, 저널/학회, 연도)
- 링크/DOI:
- 읽은 날짜 / 읽은 깊이(Pass 1·2·3):
- 검증 상태(reading_list 기준): ✅ / ⚠️

## 한 문장 요약
"[입력]으로 [모델]을 [목적함수]로 학습해 [과제]에서 [주장]."

## 체크리스트
| 항목 | 내용 |
|---|---|
| 토큰/입력 | |
| 목적함수 | |
| 사전학습 데이터(범위·중복 제거·시점) | |
| 평가-사전학습 겹침 가능성 | |
| split 방식 | |
| baseline(단순/전통) | |
| 평가 설정(zero-shot/probe/fine-tune) | |
| 통계(반복·신뢰구간) | |
| 실험적 검증 여부 | |
| 코드·가중치·라이선스 | |
| 저자가 밝힌 한계 | |

## 내가 이해한 핵심 아이디어 (3줄)

## 의심스러운 점 / 확인할 점

## 재현 계획 (해 볼 수 있는 가장 작은 실험)

## 관련 논문 / 다음에 읽을 것
```

캡스톤 평가 루브릭

8개 차원을 각각 0~3점으로 매기며 만점은 24점이다. 증거(파일·셀·표)를 적고 점수를 매긴다. 자기 평가와 독립 검토(사람 또는 모델)를 모두 받아 차이가 큰 차원을 논의한다. 아래 합격·전문가 기준은 이 과정이 제안하는 임의의 기준이며 표준이 아니다.

점수의미
0없음 또는 잘못됨
1부분적: 있으나 핵심 요소가 빠짐
2충족: 아래 “2점” 항목을 모두 만족
3우수: “2점” + “3점” 항목

차원별 기준¶

#차원1점2점 (충족)3점 (우수)
1질문과 주장 범위질문은 있으나 범위·한계가 없다한 문장 질문, 주장할 수 있는 최대 범위, 말할 수 없는 것 명시+ 반증 가능한 결정 규칙과, 실질적 의미가 있는 효과 크기 기준을 사전에 정의
2사전 등록과 변경 관리제안서는 있으나 주 비교·결정 규칙이 모호분할·지표·주 비교·결정 규칙을 결과 전에 고정, 변경 기록+ 변경이 결과를 본 뒤였는지 구분, 탐색적 분석을 사전 지정 분석과 분리해 표시
3데이터·출처·누출출처만 있고 해시·리비전·라이선스 근거가 없거나, 누출 점검이 분할 이름뿐해시·리비전·버전 기록, 중복 제거, 라이선스를 찾아 본 증거(또는 “미확인” 명시), 분할별 누출을 숫자로 측정+ 분할이 막지 못한 경로를 찾아 층화·더 엄격한 분할로 영향을 점검
4baseline과 대조군baseline 1개, 또는 모델과 다른 절차로 평가파라미터를 학습하지 않는 baseline(train 라벨 사용 가능, train에서만 추정) · 단순 특징 · 무작위 초기화를 포함한 3개 이상, 같은 절차·같은 분할+ 선택 효과/사전학습 기여를 분리하는 대조(무작위 초기화를 시드마다 새로, 학습 안 한 사전 등)와 음성 진단(라벨·입력 섞기, 증명이 아니라 진단)
5평가와 불확실성시드 평균만, 또는 구간이 상관 단위를 무시시드·분할 반복, 짝지은 비교, 상관 단위 그룹 부트스트랩(test 군집이 충분할 때, 조건부 구간임 명시). 군집이 부족하면 계산하지 않는 이유를 쓰고 시드별 값·일관성·사전 정한 효과 크기 규칙으로 판단, 지표 정의(풀링·동점·갤러리) 명시, 시드 반복은 같은 데이터의 재분할이라 독립 반복이 아님을 명시+ 한 요인씩의 민감도, 설정 선택이 test와 분리(사전 고정 또는 중첩 검증), 통계량 구분(중앙값의 차이 vs 차이의 중앙값)
6재현성노트북은 있으나 환경·시드 미기록깨끗한 환경에서 끝까지 실행, provenance 기록, 실행본 코드 = 제출 코드+ 숫자 문장·표를 코드로 생성해 서술-출력 일치 점검, 반복 실행 결과 비교, 시간·비용 보고
7해석과 한계해석은 있으나 일반화 한계·미실시 목록이 없다“직접 지지 / 가설 / 말할 수 없음” 구분, 음성·예상 밖 결과를 있는 그대로, 하지 않은 것 목록+ 대안 설명을 직접 점검한 실험, 불확실한 서술의 표시(†)
8책임성과 소통일부만 언급데이터·모델 사용·공개 권리를 사용 전에 확인(확인 못 했으면 공개·재배포 범위를 제한), 이중 용도 검토와 공개 범위 결정, 구조가 분명한 보고서+ 모델/데이터 카드 수준 문서화, 독립 검토 지적을 검증해 수용·기각 근거 기록

자동 상한 (red flag)¶

아래 중 하나라도 있으면 해당 차원(괄호)은 최대 1점이다.

  • 설정(층·에폭·LR·임계값·키워드 등)을 test 결과로 골랐고 그 test 결과를 주 결과로 보고했다("사전 고정"이라고 썼는지와 무관). 별도 test가 없으면 탐색적 결과로 표시해야 상한이 풀린다. (2, 5)

  • 분할 후 누출을 재지 않고 "누출 없음"이라고 썼다. (3)

  • 표준화·PCA·특징 선택·정규화 선택을 test를 포함한 데이터로 적합했다. (3, 5)

  • 서술의 숫자가 실행 출력과 다르다. (6, 7)

  • 음성·예상 밖 결과를 빼거나 일반화 문장(“FM은 …하다”)으로 바꿨다. (7)

  • 검토 지적을 검증 없이 수용하거나 근거 없이 무시했다. (8)

  • 고정하지 않은 리비전, 읽지 않은 원격 코드, 출처를 확인하지 않은 가중치/pickle을 썼다. (3, 8)

  • 접근 승인(gated) 모델·데이터의 약관을 사용자 대신 동의했다. (8)

제안 기준은 임의의 기준이며 다음과 같다. 합격은 합계 16 이상이고, 0점인 차원이 없으며, red flag가 없는 경우다. 전문가 수준 체크포인트는 합계 20 이상이고 모든 차원이 2 이상이며 red flag가 없는 경우다. 루브릭은 절차의 질을 보며 결과의 크기나 새로움은 보지 않는다. 음성 결과도 만점이 될 수 있다.

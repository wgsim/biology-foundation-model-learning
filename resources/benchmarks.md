# 벤치마크 지도

작성: 2026-11-06. 생물학 FM 평가에서 자주 만나는 벤치마크가 **무엇을 묻고, 무엇을 말할 수 없는지**를 정리한 표다. 서지·초록 수준 서술은 `reading_list.md`와 같은 방식으로 확인했다(범례는 그쪽 참조).

**이 문서가 하지 않는 것**
- **리더보드 점수·순위를 적지 않았다.** 점수는 버전·집계 방식·모델 목록이 바뀌며, 옮겨 적으면 금방 낡는다. 공식 사이트/논문에서 *버전을 확인하고* 읽는다.
- 이 저장소에서 직접 측정한 값은 각 모듈 README의 "이 데이터에서 본 것"에 있다. 아래 "이 저장소" 열이 그 위치를 가리킨다. 그 값들은 소형 모델·소수 시드·한 데이터셋의 결과라 **벤치마크 공식 점수와 비교할 수 없다**.
- 표의 "말할 수 없는 것"은 작성자의 판단이다(논문 주장이 아니다).

## 벤치마크를 쓰기 전 질문 7개 (모듈 06 §6 요약)
1. 라벨의 출처는 무엇인가 — 실험 / 사람 주석 / 서열 유사성으로 옮긴 주석(누출 경로)
2. 분할은 어떤 누출을 막고, 무엇을 막지 못하는가 — **분할 후 겹침을 숫자로 쟀는가**
3. 지표는 과제에 맞는가 — 평균 하나인가, 유형별·불확실성이 있는가
4. 단순 baseline(파라미터를 학습하지 않는 것, 단순 특징, 무작위 초기화)이 같은 절차로 들어 있는가
5. 사전학습 데이터와 평가 데이터가 겹칠 수 있는가 — 확인했는가
6. 같은 test를 반복해서 보며 모델을 고르면 test에 적합된다 — 숨겨진 test/버전 고정이 있는가
7. 데이터 버전·라이선스가 명시되어 있는가

## 새 벤치마크를 읽을 때 (3분 점검)
- [ ] 논문 초록의 "우리 데이터에서 최고"를 그대로 믿지 않았다 — 설정 선택이 test에서 이뤄졌는지 본다
- [ ] 분할 규칙을 한 줄로 적었고, 막지 못하는 경로를 적었다
- [ ] 점수 표에 **단순 baseline 행**이 있다. 없으면 직접 추가한다 (모듈 07 점검표)
- [ ] 평균 점수와 유형별/과제별 점수를 모두 봤다
- [ ] 버전을 고정했다 (공식 사이트의 리더보드는 갱신될 수 있다)

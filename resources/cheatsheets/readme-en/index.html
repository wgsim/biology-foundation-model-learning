Cheatsheets

English translation. AI-assisted translation of the Korean original. The Korean original is authoritative and may be newer. Links to pages without an English version open the Korean original. In the cheatsheets’ code blocks only the comments and message strings were translated; the executable code is unchanged.

One page each for the patterns and calculations actually used in the modules. The python blocks of each file were run in order and confirmed in the repository environment (.venv) (the asserts inside the blocks must pass). A bash block was not run unless marked. They must be re-checked with new models and with other library versions.

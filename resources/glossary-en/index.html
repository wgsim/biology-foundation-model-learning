Written: 2026-11-06. The terms used in this course (modules 00–07), organized with explanations (written in Korean in the original). Details specific to a model or a paper (size, data scale, etc.) are not written here; they are in reading_list.md and in each module README. The last column of the tables is the module where the term was first or most thoroughly covered. The definitions follow the meaning used in this course, and where the usage differs by field, it is noted in the remarks.

1. Models and training¶

TermEnglishExplanationModule
파운데이션 모델foundation model (FM)A model that is pretrained on large-scale data and then used for many downstream tasks. Even if it is called an “FM”, it does not always beat a simple baseline00, 04
사전학습pretrainingThe stage of first learning a general representation from large-scale unlabeled (or weakly labeled) data01
자기지도 학습self-supervised learningThe learning signal is made from the input itself (guessing masked tokens, predicting the next token, etc.)01
마스크 언어모델masked language model (MLM)An objective that masks some tokens and guesses them. Used by ESM-2, DNABERT and Nucleotide Transformer01
자기회귀autoregressivePredicting the next token from the preceding tokens. Suited to generation. ProGen, the Evo family01
대조학습contrastive learningLearning to bring matching pairs close and non-matching pairs far. CLIP, sequence–text alignment05
InfoNCEInfoNCEA contrastive loss that treats the other items in the batch as negatives and solves the classification in which “the same index is the answer”. If all the logits look the same, the initial loss is ln(batch size)05
확산 모델diffusion modelGeneration by removing noise step by step. RFdiffusion, the structure-generation part of AlphaFold 302
토크나이저tokenizerThe rule for cutting a sequence into the units of model input01
k-merk-merA contiguous subsequence of length k. It can be used overlapping or non-overlapping01
BPEbyte-pair encodingTokenization that builds the vocabulary by repeatedly merging pieces that often occur together. Adopted by DNABERT-2 (the early DNABERT used overlapping k-mers)01, 03
임베딩embeddingA vector that represents a sequence, a cell or a molecule. It depends on which layer of the model and how it was pooled01
평균 풀링mean poolingAveraging the per-token vectors into a single vector for a sequence. Check whether padding and special tokens (<cls>, <eos>) were excluded02
선형 probelinear probeAn evaluation that trains only a linear model (Ridge, etc.) on frozen embeddings to see whether the representation holds the information02
동결frozenThe pretrained weights are not updated02, 06
미세조정fine-tuningUpdating even the pretrained weights with task data. Risk of overfitting and forgetting06
few-shotfew-shotGiving only a few task examples (a prompt or a small amount of training). With no examples it is zero-shot, and with all of them it is ordinary supervised learning. A setting not covered in this course—
분포 이동distribution shiftA state in which the distributions of the training and evaluation (deployment) data differ. Splitting by new positions, new families and new donors imitates it04, 07
매개변수 효율 미세조정parameter-efficient fine-tuning (PEFT)Training only a small subset of parameters (LoRA, etc.)06
LoRAlow-rank adaptationAdds a low-rank decomposition matrix to the frozen weights and trains only that matrix. It reduces the trainable parameters and the optimizer memory, but the forward and backward computation remains06
LP-FTlinear probing then fine-tuningThe order of first training only the head (linear probe) and then fine-tuning the whole. A method meant to reduce the damage that the large gradients of a randomly initialized head do to the pretrained representation†. Not run in this repository06
스케일링 법칙scaling lawThe empirical relationship between model size, data, compute and loss. It may differ by domain (sequences)01
어텐션attentionAn operation that mixes the context by a weighted sum between tokens. The standard implementation makes an L×L score matrix, so time and memory grow as L² (FlashAttention-type methods do not store the score matrix and so reduce memory, but the amount of computation is still L²†)01
FlashAttentionFlashAttentionA CUDA implementation that computes exact attention tile by tile and reduces memory I/O†. Not available on Mac MPS06
상태공간 모델 / 장거리 합성곱state-space model (SSM) / long convolutionA family that processes long sequences at a lower cost than attention. Mamba is an SSM and Hyena is an implicit long convolution, and DNA models such as HyenaDNA and Caduceus use them for long-range context01, 03
혼합 정밀도mixed precisionHalf-precision (bf16/fp16) computation + an fp32 copy of the weights. The gain is mainly in speed and activation memory06
그래디언트 체크포인팅gradient checkpointingTrades time for memory by not storing some activations and recomputing them in backpropagation06
데이터 병렬data parallel (DDP)Replicates the model, splits the data and averages the gradients06
ZeRO / FSDPZeRO / FSDPA method that reduces the memory of one device by storing the parameters, gradients and optimizer state split across devices†06
zero-shotzero-shotPredicting from only the output of the pretrained model, without training for that task02
헤드headA small prediction module (a linear layer, etc.) placed on top of the embeddings02
리비전 고정revision pinningFixing a model/data to a specific commit hash of the repository to secure reproducibility05, 07

2. Evaluation, statistics and research methods¶

TermEnglishExplanationModule
누출leakageA state in which information used for evaluation has leaked into the training process (split, preprocessing, setting selection)01, 07
상동성 분할homology splitA split that divides train/test by a sequence-identity threshold or by family01
위치 블록 분할position-block splitA split that groups consecutive position intervals together (blocking the leakage of other substitutions at the same position)07
scaffold 분할scaffold splitA split that puts molecules with the same Bemis–Murcko scaffold on the same side. Molecules can still be similar even if the scaffolds differ05
시간 분할time splitSplitting train and test by publication/measurement time05
기증자 단위 분할donor-level splitSplitting so that cells of the same donor do not straddle train and test04
LODOleave-one-donor-outA cross-validation that leaves one donor as test04
transductive 적합transductive fittingFitting the preprocessing (HVG selection, scaling, PCA, batch correction) without labels, including the held-out samples. It is not label leakage, but it can favor that baseline, so the result fitted with only the training folds is looked at together as a sensitivity check04, 07
오염contaminationThe evaluation data is in the pretraining corpus01
baselinebaselineA comparison reference method. In this course: ① one that learns no parameters, ② simple features, ③ a randomly initialized model07
무작위 초기화 대조군random-init controlA model initialized from the same architecture without pretraining. It separates the contribution of pretraining. It is created fresh for each seed04, 07
음성 대조negative controlLook at the score when the signal is absent by shuffling labels/inputs. A diagnostic, not proof that leakage is absent05, 07
선택 효과selection effectThe performance difference created by the procedure itself of picking, among candidates, the one with the highest train score06
짝지은 비교paired comparisonComparing by taking the score difference of two methods on the same split and the same items04, 07
그룹 부트스트랩group bootstrapObtains an interval by resampling the correlation unit (groups) with replacement. It is meaningless when there are few test clusters07
조건부 구간conditional intervalAn interval obtained by fixing the training and initialization and redrawing only the test. It does not reflect the training variation07
Spearman 상관Spearman correlationRank correlation. Undefined (NaN) for a constant prediction02
AUROCROC-AUCThe probability that a randomly chosen positive is scored higher than a negative (ties count 1/2). A ranking performance, separate from probability calibration. For fold models, compute the scores per fold and average05
AUPRCaverage precision (AP) / PR-AUCSuited to classification with rare positives. average_precision_score is AP, a step-wise integral, and differs slightly from the trapezoidal area of the PR curve. The random baseline is roughly the positive fraction (depends on prevalence)03
macro-F1macro-averaged F1The simple average of per-class F1. Treats classes equally in imbalanced data04
균형정확도balanced accuracyThe simple average of per-class recall. The uniform-guess baseline is the inverse of the number of classes in that evaluation set04, 07
Recall@krecall@kThe fraction of cases where the correct answer is within the top k (when there is one correct answer per query; with several, distinguish the number of correct answers found / the total number of correct answers from the hit rate of “found at least one”). Depends on the gallery size and the tie rule05
갤러리galleryThe candidate set from which the correct answer must be chosen in retrieval05
ties-against-truthties-against-truthA conservative tie rule that counts candidates with a score equal to the correct answer as ahead of it05
사전 등록preregistrationFixing (committing) and recording the split, metrics, primary comparison and decision rule before producing the results07
결정 규칙decision ruleThe condition that decides “supported/not supported”. Fixed as a function in code07
민감도 분석sensitivity analysisChange only one factor at a time and see how much the conclusion changes. Not used to choose settings05, 07
효과 크기effect sizeThe size of the difference (separate from statistical significance). Decide the minimum meaningful difference in advance07
red flagred flagA procedural defect in the rubric that automatically lowers the score of the corresponding dimension07
재현성reproducibilityGetting the same result with the same code and data. Record the environment, seeds and hashes07
DOMEDOMERecommendations for reporting the validation of supervised ML in biology (data, optimization, model, evaluation)01

3. Proteins¶

TermEnglishExplanationModule
아미노산 서열amino-acid sequenceA string of the 20 standard amino acids. Single-residue tokenization is the default01
MSAmultiple sequence alignmentHomologous sequences aligned. Input/training information of models such as AlphaFold 2 and EVE02
DMSdeep mutational scanningAn experiment that measures the effects of many variants at once. It has noise02
적합도fitnessThe functional/growth score of a variant measured in DMS. Its goal differs from clinical pathogenicity02
상위성epistasisVariant effects are not a simple sum but depend on each other02
masked marginalmasked marginalScores by the difference between the log probabilities of the variant amino acid and the wild type when the variant position is masked. Distinguish it from the wild-type marginal (scoring all positions with 1 pass of the wild-type sequence without masking; cheap but the wild-type residue is visible in the input) and from the ratio of the pseudo-log-likelihoods (PLL) of the variant and wild-type sequences (expensive but extendable to multiple variants)02
contact mapcontact mapA matrix of whether residue pairs are close in 3D. There are studies that read it from attention. To evaluate predictions, the precision of the top L (or L/5) predictions (precision@L/5) is often used (module 02 notebook 03)02
pLDDTpredicted LDDTPer-residue confidence of a structure prediction (0–100)02
PAE / pAEpredicted aligned errorThe expected error of the position of another residue when aligned on one residue (per residue pair)02
pTM / ipTMpredicted TM-score / interface pTMPredicted scores of the structural accuracy of the whole/interface02
inverse foldinginverse foldingDesigning a sequence from a backbone structure. ProteinMPNN, ESM-IF102
de novo 설계de novo designDesigning from scratch a protein that is not in nature. A subject of dual-use review02, 06
임상 병원성 예측clinical variant pathogenicity predictionPredicting whether a human variant is associated with disease. AlphaMissense, EVE02

다의성 / superpositionpolysemanticity / superpositionA hypothesis that the phenomenon of a neuron responding to several concepts arises because the network represents more features than the number of neurons by superposing them06

접근 승인(gated) 모델gated modelA model/data that needs agreement to terms. An agent does not agree on your behalf05
pickle / trust_remote_codepickle / trust_remote_codeSerialization/remote code that can be a code-execution path. Only after pinning the revision and reviewing05
모델 카드model cardA document describing a model’s use, performance and limitations07
